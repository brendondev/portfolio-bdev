WooCommerce + Moodle API

WooCommerce ↔ Moodle Integration

Sistema completo de venda e entrega automática de cursos

📋 Visão Geral

Desenvolvimento de uma camada de integrações via snippets em PHP, conectando WooCommerce + API do Moodle para automatizar matrícula, cancelamento e comunicação com o aluno, transformando o WordPress em uma plataforma de vendas real de cursos com entrega automática.

✅ Integrações Implementadas

✅
1) Matrícula Automática

Snippet que monitora status do pedido WooCommerce e, após pagamento confirmado, executa matrícula no Moodle via API automaticamente.

❌
2) Cancelamento/Remoção de Acesso

Lógica inversa: se pedido for cancelado/reembolsado, o sistema remove ou bloqueia o acesso no Moodle automaticamente.

📧
3) E-mails Automáticos Pós-compra

Após matrícula, dispara e-mails automáticos com instruções de login, link direto e orientações claras para o aluno.

📚
4) Aba "Meus Cursos" no WooCommerce

Criada aba exclusiva em "Minha Conta" que lista cursos ativos do aluno com link direto para acessar cada um.

🔒
5) Restrição Inteligente de Páginas

Snippet que restringe páginas para alunos com curso ativo e exibe aviso fixo com CTA para "Meus Cursos".

📝
6) Campo de Vínculo no Admin

Campo no admin do WooCommerce para vincular produto ao curso Moodle, permitindo escalar catálogo sem código.

📊
7) Box de Informações no Pedido

Box na tela do pedido WooCommerce com curso vinculado, ID, link direto e status da matrícula para suporte rápido.

🛠️ Tecnologias Utilizadas

WordPress WooCommerce PHP Moodle API Snippets Customizados Automação WooCommerce

📈 Resultados

✅ Venda de cursos automatizada (sem trabalho manual) ✅ Matrícula imediata após pagamento ✅ Remoção automática de acesso após reembolso ✅ Menos dúvidas no WhatsApp (e-mails claros) ✅ WordPress vira painel central de acesso (como Hotmart) ✅ Suporte e auditoria muito mais rápidos ✅ Escala simples para novos cursos/produtos

🎯 Diferenciais

  • Entrega 100% automática após compra
  • Sem dependência de suporte manual
  • Experiência profissional como grandes plataformas
  • Controle de acesso inteligente e seguro
  • Painel administrativo completo para operação
  • Estrutura preparada para escalar
